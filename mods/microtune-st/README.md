# microtune-st (draft: waits on a core hook)

Microtuning for the Syntakt: each of the 12 pitch classes is moved by up to
±100 cents, from a root note, on all 12 tracks.

This folder holds the parts that do not depend on the core:

| file | what |
|---|---|
| `tune.h` | the map, in plain C: `mt_prepare` turns 12 offsets (0.1 cent each) and a root into a table, `mt_map` moves a Q16 pitch (60<<16 = C4) by it, with the offset interpolated between semitones so pitch bends and slides stay continuous |
| `tunings.h` | the factory tunings, generated by `tools/microtune.py --write`; do not edit by hand |

Factory tunings: 12-TET, JUST MAJOR, JUST MINOR, PYTHAGOREAN, MEANTONE 1/4,
WERCKM. III, KIRNB. III, VALLOTTI, ARABIC RAST, POOLE ROD12.

Any 12-note Scala file with a 2/1 octave whose notes stay within 100 cents of
12-TET converts with:

```bash
python tools/microtune.py scl my-scale.scl          # the 12 offsets
python tools/microtune.py scl my-scale.scl --c NAME # as a C row
```

## What is missing

The module needs a core event that sees each track's pitch after the
firmware computes it and before the engines read it. The proposed site is
`ST_NATIVE_PITCH` at 0x400a4bb8, after the loop at 0x400a4b6a..0x400a4bb6
that writes all 12 tracks' Q16 pitch to 0x80004688+4t; see the microtuning
issue. Until the core has it, there is no `mod.json` and nothing to build.

## Tests

```bash
python tests/test_st_microtune.py [--cc cc] [--cross m68k-elf-gcc]
```

Checks `tunings.h` is current, that POOLE ROD12 equals its .scl, that bad
scales are refused, and compares `mt_map` with an exact reference over every
tuning, root and a sweep of pitches (semitones exact, 12-TET the identity,
pitch always rising, offsets clamped). With a ColdFire compiler it also
compiles the headers with `-Wall -Werror`.
