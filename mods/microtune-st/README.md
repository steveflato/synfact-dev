# microtune-st (prototype)

Microtuning for the Syntakt: each of the 12 pitch classes is moved by up to
±100 cents, from a root note, on all 12 audio tracks.

**Needs core 2.9.0-mt1** (a prototype core with `ST_NATIVE_PITCH`, host
API 21). On an older core the module does not start and nothing changes.

## Use

- **SETTINGS > TUNING**: OFF, or one of the factory tunings. YES steps
  forward; LEFT/RIGHT step either way.
- **SETTINGS > TUNE ROOT**: the note the tuning is built from (C..B).
- **SETTINGS > TUNE TRACKS**: which tracks are tuned. LEFT/RIGHT move
  through T1..T12 and ALL; YES switches the shown track on or off (ALL: every
  track on, or every track off), so drums can keep 12-TET.

- **SETTINGS > A4**: the reference pitch, 400..480 Hz (default 440). LEFT/RIGHT
  move 1 Hz; YES returns to 440. It moves every enabled track by the same
  offset, 12 * log2(Hz / 440) semitones, with or without a tuning (a tuning's
  cents are then relative to this A4).

All four are kept across power-off (core preferences, key 4: tuning, root,
track mask; key 5: A4 in Hz, a record of its own). With no track on, or TUNING
OFF (or a flat tuning) and A4 at 440, the module declares no PITCH interest,
so MAIN takes the stock short path and every pitch is exactly stock. The interest changes only when that state
changes, in an IRQ-masked section.

| file | what |
|---|---|
| `main.c` | the module: the PITCH subscriber (MAIN IRQ: one pointer read and the map, no allocation), the two SETTINGS rows and the preferences |
| `tune.h` | the map, in plain C: `mt_prepare` turns 12 offsets (0.1 cent each) and a root into a table, `mt_map` moves a Q16 pitch (60<<16 = C4) by it, with the offset interpolated between semitones so pitch bends and slides stay continuous |
| `tunings.h` | the factory tunings and the A4 table (Q16 semitones per Hz, 400..480), generated by `tools/microtune.py --write`; do not edit by hand |

Factory tunings: 12-TET, JUST MAJOR, JUST MINOR, PYTHAGOREAN, MEANTONE 1/4,
WERCKM. III, KIRNB. III, VALLOTTI, ARABIC RAST, POOLE ROD12.

Any 12-note Scala file with a 2/1 octave whose notes stay within 100 cents of
12-TET converts with:

```bash
python tools/microtune.py scl my-scale.scl          # the 12 offsets
python tools/microtune.py scl my-scale.scl --c NAME # as a C row
```

## How it works

MAIN's IRQ pass writes each track's Q16 pitch to `80004688 + 4*track`
(loop `400a4b6a..400a4bb6`). The core replaces the next instruction
(`400a4bb8`) with a jump to `core_native_pitch`, which hands the 12 words to
the native bus before the audio frame reads them. This module edits them in
place. A new tuning is prepared in a second table and switched in with one
pointer store, so MAIN never sees a half-written table.

Not yet: Scala files loaded on the unit, more than 12 notes per octave, a
per-kit record.

## Tests

```bash
python tests/test_st_microtune.py [--cc cc] [--cross m68k-elf-gcc]
python tests/test_st_microtune_module.py [--cc m68k-elf-gcc]
```

Checks `tunings.h` is current, that POOLE ROD12 equals its .scl, that bad
scales are refused, and compares `mt_map` with an exact reference over every
tuning, root and a sweep of pitches (semitones exact, 12-TET the identity,
pitch always rising, offsets clamped). With a ColdFire compiler it also
compiles the headers with `-Wall -Werror`.
